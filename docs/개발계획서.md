# 코스피/코스닥 주간 수급동향 수집 프로그램 — 개발 계획서

> 작성일: 2026-03-01
> 상태: 개발 준비 완료 (KIS APP Key/Secret 발급 완료)

---

## 1. 프로젝트 개요

매주 금요일 20:00 KST, 코스피·코스닥 전 종목 데이터를 자동 수집 → Excel 저장 → 시총 비중 가공 → SQLite 누적 DB 저장 → 시계열 차트 생성 → AI 보고서(Markdown) 자동 작성하는 로컬 Python 프로그램.

### 핵심 요건
- 실행 환경: Mac 로컬
- 실행 주기: 매주 금요일 20:00 KST (자동 스케줄) + `--run-now` 즉시 실행 옵션
- 출력물: Excel(5탭) + Markdown 보고서 + 차트 PNG 6종
- 누적 분석: SQLite에 최대 52주(1년) 이력 보관

---

## 2. 전체 파이프라인

```
[1] crawler.py     KIS API + pykrx + 네이버금융 → 주차 DataFrame
        ↓
[2] processor.py   파생 컬럼 계산 + 시총 구간별 비중 계산 + 업종별 집계
        ↓
[3] database.py    SQLite(history.db)에 주별 데이터 UPSERT (최대 52주 유지)
        ↓
[4] exporter.py    주간 Excel 저장 (5탭, 주간수급동향_YYYYMMDD.xlsx)
        ↓
[5] visualizer.py  SQLite 이력 조회 → 차트 PNG 6종 생성 (data/charts/)
        ↓
[6] reporter.py    요약 데이터 + 차트 경로 → claude-sonnet-4-6 → 주간수급동향_YYYYMMDD.md
```

## 3. 데이터 소스 전략

### 사용 도구
| 도구 | 역할 |
|------|------|
| **KIS API** (python-kis) | 전종목 시가총액·거래대금·PER·PBR·배당수익률 (공식 REST API) |
| **pykrx** | 기관/외국인 순매수 기간별 Bulk 합산 + 등락률 계산 |
| **네이버금융 크롤링** | 섹터(업종), 재무데이터, 컨센서스 (유일한 무료 소스) |

### 필드별 소스 매핑 (총 34개 필드)

| 필드 | 소스 | 방법 |
|------|------|------|
| 티커, 종목명, 시가총액, 거래대금 | KIS API | 전종목 시세 일괄 조회 |
| PER, PBR, 배당수익률 | KIS API | 종목별 현재가 상세 |
| 섹터(업종) | 네이버금융 | 크롤링 |
| 1주/1개월/3개월/6개월 등락률 | pykrx | 기간별 종가 → 수익률 계산 |
| 기관 순매수대금 (1주/2주/한달/3개월) | pykrx | `get_market_trading_value_by_ticker(date)` 일별 Bulk 합산 |
| 외국인 순매수대금 (1주/2주/한달/3개월) | pykrx | 위와 동일 |
| 작년/예상 매출액·영업이익·ROE | 네이버금융 | 크롤링 (컨센서스는 대형주 위주, 없으면 N/A) |
| 영업이익률 | 계산 | 영업이익 ÷ 매출액 |
| 부채비율, 유보율 | 네이버금융 | 크롤링 |
| 매출액/영업이익 증가율 (전년동기대비) | 네이버금융 | 크롤링 |
| 증시 지수, 주간 투자자별 수급 | pykrx | `get_index_ohlcv_by_date`, `get_market_trading_value_by_date` |
| **시총대비 기관순매수비중(1주)** | 계산 | 1주기관순매수 ÷ 시가총액 × 100 |
| **시총대비 외국인순매수비중(1주)** | 계산 | 1주외국인순매수 ÷ 시가총액 × 100 |

> 컨센서스(예상치) 데이터는 애널리스트 커버리지 종목만 존재. 없는 종목은 N/A 처리.

        stock_count=("티커", "count"),

-- 주별 증시 수급 정보

-- 주별 시총 구간 비중
CREATE TABLE IF NOT EXISTS weekly_cap_weight (
    week_date TEXT,
    market TEXT,
    group_name TEXT,
    stock_count INTEGER,
    group_cap REAL,
    total_cap REAL,
    weight_pct REAL,
    PRIMARY KEY (week_date, market, group_name)
);

-- 주별 업종별 수급 집계
CREATE TABLE IF NOT EXISTS weekly_sector (
    week_date TEXT,
    market TEXT,

    total_market_cap REAL,    -- 업종 시총 합(억)

    inst_cap_ratio REAL,      -- 업종 시총 대비 기관 비중(%)
    avg_return_1w REAL,       -- 업종 평균 주간 등락률(%)
    PRIMARY KEY (week_date, market, sector)

# scheduler.py
scheduler.add_job(run_pipeline, "cron",
                  day_of_week="fri", hour=20, minute=0,
                  timezone="Asia/Seoul")

# main.py
def run_pipeline():
    raw  = crawler.collect_all()         # [1]
    data = processor.process(raw)        # [2]
    database.upsert_week(data)           # [3]
    exporter.save_excel(data)            # [4]
    visualizer.generate_charts(data)     # [5]
    reporter.generate_report(data)       # [6]

if __name__ == "__main__":
    if "--run-now" in sys.argv:
        run_pipeline()
    else:
        scheduler.start()
